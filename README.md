# kirra-docs

User-facing documentation for **Kirra Design** and **Kirra Scheduler**.

- **Search:** [brentbuffham.github.io/kirra-docs/search.html](https://brentbuffham.github.io/kirra-docs/search.html), or the search box at the top of every page. The index (`search.json`) is rebuilt by GitHub Pages on every push, so new pages are searchable without any extra step. A page can opt out with `search: false` front matter.
- Start here: **[index.md](index.md)** — table of contents, all guides, and **documentation freshness** (Kirra version + git commit reviewed against).
- **Formula Engine:** [formula-help/formula-engine.md](formula-help/formula-engine.md) (HTML: [formula-engine.html](formula-help/formula-engine.html)) — hub for charging, print, and blast-group `fx:` formulas; [Claude skill install](formula-help/formula-skill.md) and [kirra-formula.zip](formula-help/kirra-formula.zip).
